# Support

Use the repository's structured Issue Forms for engineering work:

- **Bug / Incident** for failures and regressions;
- **Feature Request** for new capabilities;
- **Investigation** or **Spike / Research** for evidence-first analysis;
- **Architecture Decision / ADR** for significant technical decisions;
- **Implementation Task** for bounded delivery work;
- **Review Finding** and **Security Finding** for independently verifiable findings;
- **Model Evaluation** for model/routing experiments.

For project-specific operational instructions, check the repository README, `AGENTS.md`, specifications and implementation plans before opening an issue.
